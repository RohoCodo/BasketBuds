# Harvest

Astro + TypeScript website inspired by the provided mockup: a softly blurred garden atmosphere, warm cream content cards, and a three-role selector for Gardener, Farmer, and Harvester.

## Tech Stack

- Astro
- TypeScript
- CSS (custom theme variables + responsive layout + subtle motion)

## Scripts

- `npm run dev`: start local development server at `http://localhost:4321`
- `npm run build`: build production output to `dist/`
- `npm run preview`: preview production build locally

## Run and Debug

1. Start the dev server: `npm run dev`
2. Open the local URL shown in terminal (`http://localhost:4321` by default)
3. In VS Code, you can run the created task named `Astro: Dev Server`

## Notes

- The homepage implementation is in `src/pages/index.astro`
- Global page theming is in `src/layouts/Layout.astro`
